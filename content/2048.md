# LibraryOf2048: A Rust-Based GUI Viewer for All ~117 Quintillion 2048 Game States

**Project URL:** [https://jwm.place/libraryof2048/](https://jwm.place/libraryof2048/)  
**Source Code:** [https://github.com/jwm-dev/LibraryOf2048](https://github.com/jwm-dev/LibraryOf2048)

---

## Overview

**LibraryOf2048** is a Rust-based application that catalogs and indexes all approximately 117 quintillion possible board states of the classic 2048 game. Inspired by Jonathan Basile’s Library of Babel, this project provides a deterministic, navigable archive of all valid 4×4 tile configurations using a two-part keying system that enables efficient enumeration and lookup. The project includes a GUI interface and serves as a platform for further research into solving the stochastic dynamics of 2048, a PSPACE-complete challenge.

---

## Technical Architecture

### Core Technologies

- **Rust**: The primary programming language, chosen for its performance and safety features.
- **GTK4**: A toolkit for creating graphical user interfaces, utilized for the application's GUI.
- **Serde**: A framework for serializing and deserializing Rust data structures, used for data handling.

### Project Structure

The repository is organized as follows:

- `src/`: Contains the main application code, including initialization, rendering logic, and event handling.
- `Cargo.toml` and `Cargo.lock`: Define the project's dependencies and build configurations.

## Functionality

### Board State Enumeration

The application employs a dual-ID system and t-value to uniquely identify each board state:

- **T-Value (Tile Count)**: Represents how many tiles are present on the board.
- **Dual-ID System**: A two-part keying system that enables efficient enumeration and lookup of board states.

This system allows for the representation and navigation of all possible 2048 board configurations.

### Graphical User Interface

The GUI, built with GTK4, provides an interactive platform for users to explore the vast number of board states. It includes features such as:

- **Board Navigation**: Users can navigate through different board states using the dual-ID system.
- **State Visualization**: Each board state is visually represented, allowing users to observe the arrangement of tiles.

### Data Handling

Serde is used for serializing and deserializing data, facilitating the efficient storage and retrieval of board states.

## Implementation Details

### Rust and GTK4 Integration

The application leverages Rust's GTK4 bindings to create the GUI. This involves setting up the application window, handling user inputs, and rendering the board states.

### Board State Representation

Each board state is represented using a data structure that encodes the arrangement of tiles. The dual-ID system and t-value are used to uniquely identify and navigate through the board states.

### Serialization with Serde

Serde is utilized to serialize and deserialize the board state data, allowing for efficient storage and retrieval. This ensures that the application can handle the vast number of possible board states without performance degradation.
